# dsh-go-files

dsh-go 手机 App 里的「工作区」原生面板：在侧栏「插件」页签里逛主机的工区，看文本 / 图片 / 视频预览，把手机里的文件传进工作区，还能移动和删除。

- **在哪看**：对话详情页 → 插件页签（`session.tab`），也出现在「全部功能」和聊天页的「插件」弹层。
- **浏览**：文件夹在前；图片按两列缩略图卡片排（点卡片进详情，再点图全屏缩放、保存），视频给封面 + 无声小动图，其他文件点开看预览。
- **上传**：系统选择器选文件 → 落到工作区 `artifacts/uploads/<日期>/`（父目录不存在会自动建），同名自动加序号不覆盖。单个 ≤ 8 MiB，一次最多 4 个、合计 ≤ 16 MiB。
- **移动**：文件详情页「移动到…」→ 选目标文件夹 → 移动；不覆盖同名文件。
- **删除**：文件详情页「删除」要确认；空文件夹在它自己的页面能删；非空文件夹不允许删；符号链接和工作区外的路径一律不碰。
- **边界**：所有文件操作都限制在工作区根目录内，`../`、绝对路径、指向外面的符号链接都会被拒。

## 已知限制

- **拒绝不安全的祖先目录**：删除 / 移动 / 上传在动手前会把「从工作区根到目标父目录」的每一级都 `lstat` 一遍。任何一级是符号链接、或对 other 可写且不是 sticky → 直接拒绝（`unsafe-parent` / `changed`）。理由是威胁模型：同机的人能不能在校验后换掉祖先目录，取决于那一级能不能被改名 —— 只有属主可写时谁都不行；sticky 目录（`/tmp`，1777）放行，因为别人删不掉、也改不了我们的目录项。应用私有目录（0700）与 `/tmp` 都不会误伤。

  这个判定有两类例外，都是为了不让真机变砖：
  - **没有 POSIX 权限语义的文件系统**（vfat / exFAT / NTFS / FUSE / CIFS 等，SD 卡最常见）：它们把所有目录都报成 0777，按权限位判断会让整个工作区变成只读。插件按 `statfs` 的 magic 认出来就放行，并在日志里留一条 `[dsh-go-files] 放行对 other 可写的祖先目录（…）`，说明为什么放行。
  - **显式开关** `DSH_FILES_ALLOW_OPEN_ANCESTORS=1`：给 owner 自己的逃生口（例如工作区放在一个 0777 的自建目录里）。开了之后对 other 可写的祖先不再拒绝，风险由开它的人承担。
- **仍然是 check-then-use，不是保证**：Node 没有 `openat2(RESOLVE_BENEATH)`，也没有 dirfd 相对的 `unlinkat` / `linkat`。系统调用前会再 `realpath` + 比对 `dev:ino`，但「最后一次比对」与真正的 `unlink` / `link` 之间仍有极窄的窗口。这条防线准确的描述是**拒绝不安全祖先 + 缩小窗口**，不是「不可能越界」。
  - 上传：`mkdir` 前后、以及每次发布前各校验一次祖先链；**预览**比的是源文件末端的 `dev:ino`（`O_NOFOLLOW`，不跟随软链），不是父目录。
- **移动不是原子 rename**：`link` 之后、删源之前进程被杀会留下「源 + 目标」两份同样的文件（不覆盖、不丢数据），目标已存在时重试报「目标里已有同名文件」，需要手动删掉一份。回滚失败会返回 `source-changed-orphan` / `left-both`，面板提示会要求人工到目标目录确认。跨文件系统不能移动，直接拒绝。
- **没有 ffmpeg / ffprobe 的主机**：图片不转码，按原图复制进预览缓存，视图里标注「尺寸未校验」；只有连 1 MiB 都放不下、又没工具可转时才报 `no-tools`。视频预览必须转码，缺工具时同样明说缺工具。两个尺寸上限统一为「单边 4096，总像素 4096²」——4096×1024、2000×2000、4000×3000 这类正常图不会被自己的检查拦下。
- 上传一次最多 4 个、单文件 8 MiB、**合计 16 MiB**（插件自己核一遍，桥接层还有一层）；写到一半被杀留下的 `.upload-*.part` 不进目录列表。

## 安装

```sh
dsh plugin --profile web add dsh-go-files
# 或指定版本：dsh plugin --profile web add dsh-go-files@0.3.0
```

卸载：

```sh
dsh plugin --profile web remove dsh-go-files
```

## 工作区根目录

默认取 DSH 工作区注册表里的第一个工作区（本机就是 `/opt/miao/dev/workspace`），取不到才退回引擎当前目录；可用环境变量 `DSH_WORKSPACE_ROOT` 强制指定。

## 预览缓存

图片 / 视频预览会转存到插件自己的 `assets/preview/`（App 的 `asset:` 只能引用这里），最多留 64 个、7 天自动清理，不进 git。缓存只接受普通文件，复制/转换先写独立临时文件再原子改名，多进程同时预览也不会暴露半张图。视频预览和超大图压缩需要主机有 `ffmpeg` / `ffprobe`，没有时退化成只显示文件信息；超过 1080p 的视频只给封面，避免拖过面板 3 秒窗口。

## 开发

```sh
npm test
node "$DSH_HOME/skills/dsh-go-plugin/kit/bin/check.mjs" . --load   # 需要本机装 dsh-go-plugin 技能
```

改了 `lib/` 里的代码，要在 App 的「引擎」页重启引擎才生效；只改 `package.json` 里的清单会自动重读。

## 发布

```sh
node scripts/release.mjs <version>
```

推 `main` + `v*` tag 后由 GitHub Actions 跑测试并 `npm publish --provenance`、建 Release。市场条目见 `docs/market-entry.json`。
